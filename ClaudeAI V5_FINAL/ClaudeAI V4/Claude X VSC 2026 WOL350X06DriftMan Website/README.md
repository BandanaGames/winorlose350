# Win Or Lose 350 X 06 Drift Man

A luxury streetwear ecommerce landing page inspired by premium brands like BAPE, BBC Ice Cream, and Louis Vuitton.

## Project Structure

- `index.html` — main website page
- `styles/style.css` — design and layout
- `scripts/main.js` — interactive navigation and product actions

## Run locally

1. Open `index.html` in your browser.
2. For a local server experience, use a simple HTTP server such as `Live Server` in VS Code.

## Notes

- Replace placeholder content and imagery with brand assets.
- Put your own photos in the `images/` folder and keep the same names to swap them into the product and gallery sections.
- Or use the `Upload Your Own Photos` section in the website to preview JPG/PNG images instantly without replacing files.
- This scaffold is designed for a high-end drift-inspired fashion and lifestyle store.
